# Multisport

Une application pour suivre ses entraînements dans plusieurs disciplines et mieux comprendre sa progression.

## Pourquoi ce projet

Je pratique plusieurs sports, mais suivre sa progression devient plus compliqué quand les entraînements sont répartis entre différentes disciplines. Je voulais créer un outil qui me permette de centraliser mes séances, de garder un historique et de comprendre comment je répartis mon temps entre mes activités sportives.

Ce projet est aussi l'occasion de développer une application web plus complète, de la conception de la base de données jusqu'à l'interface utilisateur, en passant par le développement d'une API.

## Fonctionnalités prévues

- Enregistrer, modifier et supprimer une séance
- Planifier des séances et consulter son historique
- Filtrer les séances par sport
- Suivre ses entraînements en course à pied, musculation et danse classique
- Enregistrer les détails propres à chaque discipline
- Visualiser ses statistiques : temps d'entraînement, nombre de séances et répartition par sport

## Stack

React, TypeScript, Node.js, Express, Prisma et PostgreSQL.

Le projet est développé progressivement pour mettre en pratique la conception de bases de données relationnelles, la création d'API REST et le développement d'une application web full stack.
